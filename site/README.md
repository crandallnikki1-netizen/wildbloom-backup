# House of the Wild Bloom Website Rebuild

This folder contains a clean, responsive, conversion-ready static website for House of the Wild Bloom.

## Files

- `index.html` — page sections, navigation, brand story, contact links
- `styles.css` — colors, typography, responsive layout, and mid-century modern styling
- `content.js` — the editable product catalog
- `app.js` — product rendering, mobile menu, and footer year

## Preview locally

Open `index.html` in a browser, or serve the folder with any simple static server.

## Update products

Edit only `content.js` for routine catalog changes. Copy a product object to add a product, update its text, or remove its object to hide it.

## Before launch

1. Replace the CSS product illustrations with final product photographs.
2. Replace the placeholder Etsy link with the exact shop URL.
3. Connect buttons to the final ecommerce product pages.
4. Add shipping, returns, privacy, terms, and required cosmetic disclaimers.
5. Add analytics and search-engine metadata.
6. Move the final domain only after testing checkout, mobile layout, links, and email delivery.

## Safety

This build lives only on the `website-rebuild` branch. The `master` branch and original `wildbloom.tar.gz` backup remain unchanged.
